# Хийгдсэн ажлуудын лог

## Session — 2026-11-13

### TESO ITAM-аас тусдаа төсөл болгон салгав

ITAM-ын `/finance/statement-report` (хуулгын тайлан бүтээгч, толгойн дизайнер, лого, баталгаажуулах QR,
`/verify` хуудас) энэ repo руу шилжив. ITAM дахь хувилбар хэвээр үлдсэн (хэрэглэгчийн шийдвэр).

**Шийдвэрүүд (хэрэглэгчтэй тохирсон):**
- Нэвтрэлтгүй — CORE ERP-ийн хэрэглэгч/нууц үг шаардахгүй. Оронд нь IP-ээр хүсэлтийн хязгаар
  (PDF 30/мин, лого 10/мин, шалгах 60/мин) ба аудитад IP.
- Өгөгдлийн сангүй — тайлан бүрийн баталгаажуулах бүртгэл (код, PDF-ийн SHA-256, гарчиг, хуудас/мөр,
  тайлбар, огноо, IP) ба логоны өөрчлөлт `DATA_DIR/audit.jsonl`-д мөр мөрөөр. Дараа нь сан руу импортлох боломжтой.
- QR нь өмнөх шиг тогтмол `https://itd.teso.mn/verify/<код>` (API ба вэбд ижил тогтмол). ITAM-ын шалгах хуудас
  энэ аппын кодыг одоогоор танихгүй — аппын өөрийн `/verify` хуудас бүртгэлийг уншдаг.
- PDF-ийн footer хэрэглэгчийн нэргүй ("Энэхүү тайланг TESO ITAM системд «файл» файлаас ...-д үүсгэв.").

**Бүтэц:** `api/` (Express 5 + Zod + pdfkit, `/api/v1/statement-report/{pdf,logo}`,
`/api/v1/public/statement-reports/:code`), `web/` (Next.js 16, `/` бүтээгч, `/verify`). Хөтөч зөвхөн вэб рүү
хандана — Next.js `/api/v1/*`-ийг `API_INTERNAL_URL` руу дамжуулна. Docker: вэб 3300, API 4300, `statement_data` volume.

**Review (3 агент + баталгаажуулалт) — засварууд.**
- Клиентийн IP: Next.js-ийн rewrites `X-Forwarded-For` нэмдэггүй, клиентийнхийг дамжуулдаг байсан
  (бүх хэрэглэгч нэг хязгаартай, эсвэл хуурамч толгойгоор тойрох). Одоо route handler proxy +
  `proxy.ts` клиентийн толгойг хасаж Next бодит socket хаягийг бичнэ; API `trust proxy = 1`;
  API-ийн порт зөвхөн 127.0.0.1. nginx-ийн ард `BEHIND_PROXY=true`.
- Лого: зэрэг оруулахад түр файлын нэр давхцаж 500 + худал аудит → randomUUID + дараалал;
  rename амжилтгүй бол `UPDATE_FAILED`. multer: текст талбар/олон хэсэг хориотой (санах ой).
  PDF урьдчилан харагдацын логоны SHA-256-г шалгана (зөрвөл 409 `LOGO_CHANGED`), логог нэг удаа уншина.
- Бүртгэл: кодоор шалгахад бүх файлыг уншдаг байсан → санах ойн индекс (анх readline-аар),
  тасарсан мөрийн араас шинэ мөр наалдахгүй (бичих бүрт төгсгөлийн шинэ мөр шалгана).
- Алдаа: body-parser/router-ийн 4xx алдаа 500 болдог байсан → 400/413/415. DATA_DIR-д бичих эрхгүй бол
  эхлэхдээ зогсоно; compose-д API healthcheck.
- QR-ийн хаягийн env override-ийг хасав (урьдчилан харагдац ба PDF хэзээ ч зөрөхгүй).
- Вэб: PDF тулгах SHA-256 http-ээр (LAN) ч ажиллана (`@noble/hashes`), алдааны хуудсууд, англи axios
  алдааны мессеж, дутуу CSS хувьсагч.

**Шалгалт.** api 61 тест. Template экспорт/импорт хийгээгүй (itam-ын загвар шилжихгүй — origin өөр).
